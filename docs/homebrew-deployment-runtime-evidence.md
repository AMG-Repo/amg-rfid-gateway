# Local runtime candidate metadata

`ObserveRuntimeEvidence` is an independent, Linux-only, read-only observation of an explicitly selected existing directory and a socket **candidate name** directly inside it. It accepts independently selected device/inode, owner and ordinary `0700` directory mode. It traverses components from `/` using no-follow directory handles, checks each against pathname metadata, and checks the final handle and pathname again. Unsafe ancestors, missing paths, links, changed identity, ambiguous ownership or writable ancestry are refused with sanitized status codes. Existing socket-path objects are refused. No directory or socket is created; the positive protected fixture establishes metadata observation only.

A positive result does **not** identify the directory creator, establish socket creation or safety, validate restart/crash cleanup, protect against hostile same-UID actors or mount substitution, or verify service-manager state. These races and lifecycle questions require independent evidence and controls. This observation is not wired to an apply caller or CLI. `PlanChange` remains non-authorizing with `ApplyEligible=false`, including runtime, service, network, receipt and recovery blockers even if metadata appears compatible. The device NO-GO decision remains unchanged.
