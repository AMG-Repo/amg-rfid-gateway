# AMG RFID Shared Go

Models and protocol constants shared between Gateway and Cloud backend.

## Usage

```go
import (
    sharedmodels "github.com/amg-rfid/amg-rfid-shared-go/models"
    "github.com/amg-rfid/amg-rfid-shared-go/protocol"
)
```

## Structure

- `models/` - DTOs for gateway/cloud communication
- `protocol/` - Protocol constants and packet parsing

## Versioning

Follows semantic versioning. Tag with `vX.Y.Z` for releases.
